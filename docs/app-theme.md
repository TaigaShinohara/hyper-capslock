# アプリの色（アイコンと共通のパレット）

2026-11-28 決定。本人の指示「アプリ全体の色はアイコンの色に揃える」で、macOS アプリの色を正式アイコンから採ったパレットに統一した。正本はこのファイル。実装は `mac/HyperCapsLockApp/Sources/HyperCapsLockApp/Views/AppTheme.swift`。

Mac と Windows の実機では、まだ押して確認していない。

## パレット（アイコンからの採取色）

| 名前 | 色 | アイコンのどこ | アプリでの役割 |
| --- | --- | --- | --- |
| navy | `#141E44` | 背景の濃紺 | キーキャップの輪郭など、ごく少量の補助 |
| key | `#232329` | キーキャップの黒 | 強調キーキャップの地、ヘッダーのマークの地 |
| teal | `#0A807A` | 計器盤のティール（操作色として少し深めた） | 主役。主ボタン、スイッチ、実行中の状態、成功の表示 |
| led | `#2EE6B8` | 相棒の LED の目と口 | 装飾だけに使う候補。文字には使わない（薄いため） |
| orange | `#F57D1E` | ヘッドセットと計器 | 注意の表示、強調キーキャップの輪郭 |
| yellow | `#FFD60A` | CAPS の文字 | 強調キーキャップの文字、ヘッダーのマークの ⇪ |
| pale | `#D9ECEB` | コックピット窓の淡色 | 通常キーキャップの地 |

## 使い方の決まり

- 主役は teal ひとつ。ボタン・スイッチ・選択中の色は全部 teal に寄せる（`.tint(AppTheme.teal)`）。
- 状態の色: 実行中 = teal、待ち・注意 = orange、復元失敗 = 赤（安全のためパレット外の赤を残す）、停止 = グレー。
- キーキャップ表示はアイコンと同じ組み合わせにする。通常 = pale の地に key の文字。強調 = key の地に yellow の文字、輪郭は orange。
- カードの地は明暗どちらの外観でも文字が読めるよう `primary` の薄い色にし、輪郭だけ teal で引く。pale や navy を大きな面に敷かない（ダークモードで文字が埋もれるため）。
- led は薄くて文字に使えない。使うなら点や光の装飾だけ。
- 文書（README や docs）の見た目は [アート方針](art-direction.md) が正本で、このパレットはアプリ画面だけに使う。
