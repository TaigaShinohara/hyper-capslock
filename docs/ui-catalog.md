### ページ見出し

- 役割：そのページが何かを、番号なしの H1 一つで示す。
- 使う場面：すべての利用者向けページ。
- 使わない場面：節の見出し。節は H2。手順の中の区切りは H3（最初の成功、外し方）だけ。
- 状態：通常のみ。押下、無効、エラー、読込中はなし。
- 狙い：開いてすぐにページの名前が一つ浮かぶ。番号が付くと、前のページの続きに見える。
- アート方針との対応：文字と密度の見出し。H4 は使わない。
- バリエーション：手順のページの H2 だけ番号を付ける。どちらか一方の選択は A / B。それ以外の見た目は変えない。
- 実装の場所：各 Markdown の先頭。
- 登録日と経緯：2026-11-17。既存の H1 を正本にした。

- バリエーション：ページごとに文は違う。長さを増やして第二の説明にしない。
- 実装の場所：各 H1 の直下。
- 登録日と経緯：2026-11-17。既存の冒頭文を正本にした。
